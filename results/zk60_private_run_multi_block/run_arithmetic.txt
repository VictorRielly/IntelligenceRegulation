========================================================================
NOTE on the option-B receipt estimate above
========================================================================
  It charges each seam one extra A opening group and two extra A rows.
  It does NOT model the fact that option B also re-cuts the slot
  schedule for interior blocks (block k loses its outgoing IO slot and
  block k+1's incoming IO slot gains a second private table on another
  commitment), which moves N_SLOTS, M_ROWS = 2*N_SLOTS+4, slot_terms,
  the schedule digest and every counted constant for interior blocks.
  Treat the option-B byte figure as an order-of-magnitude [MODEL]: the
  sign (option B is smaller by about 1.7%) is safe, the digits are not.
