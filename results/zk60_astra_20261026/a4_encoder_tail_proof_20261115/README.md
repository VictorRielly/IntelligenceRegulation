# Complete first image encoder development proof

The native four-stage proof joins the RGB8 frontend, N16/QKV encoder stage, full
noncausal attention and the complete encoder tail. Three retained trained canvas
cases verify. All 60 wire/statement controls and 44 serialized forged proofs
reject at their intended ordinary-verifier checks. The unit suite passes 26
tests. Two additional residual-scale parameter variants, shifts 3 and 7, verify;
these are not qualification of the trained later layers.

The residual input X is authenticated through `[Q,K,V,X]` and `[O,X]` boundaries.
The tail covers AO, residual1, norm_m, gate/up, literal SiLU, hidden product,
down projection and residual2. Its 786,432 output and 52,694,016 intermediate
reference words match across the three cases. Previous proof entry points remain
available in this isolated source copy; the qualified prior packages are frozen.

`RESULT.json` audits 399 pinned inputs and four clean resource-guard terminals.
The original tool session 28262 exited zero. The receipt suite took 690.48 seconds
and peaked at 6.52 GiB sampled RSS; the release build peaked at 5.31 GiB. Honest
proofs took 12.56–13.30 seconds and verification 0.421–0.442 seconds. These are
shared-host functional diagnostics, not benchmarks. One prepared host approval
covered type-checking, build, units and the full proof suite. The earlier sandbox
attempt failed before any leaf because the process check was unavailable.

The three internal commitments contain 70, 262 and 134 rows, each with two
independent borrowing sites and one joint opening. The tail has 22 slots, 89 A
sites, 31 H sites, 7,801 A rows and 7,368 H rows, with 30 A and 15 H opening groups.
Both byte and literal activation lookups share the signed H sum. Twenty-four
compensated limb forgeries and a complete wrong-SiLU-table witness fail global H
group 14. Five broken X/O carry cases fail their intended producer/consumer
slots. Wrong matrices, normalization constants and all six shifts are also
checked through serialized proofs and the ordinary verifier.

All model arrays remain outside the public repository. Raw receipts were
exercised in memory and are not retained for standalone replay. The source copy
changes six existing files for carry variants and helper visibility, and adds
six tail files, including the byte-identical qualified numerical oracle. There
is no registered/installed profile, main-native edit, formal-lane edit, Git write
or production/privacy acceptance.

`REVIEW.md` records the construction and review scope. `BOUNDS.json` gives
conditional integer-lifting bounds below 2^50, not a composed soundness level.
`NEXT_CHAIN_PLAN.json` authenticates all 24 layer table domains and unit
transitions, deriving the next 73-stage/74-root chain. That complete-chain proof
is not implemented here. Later-layer proof composition, projector/splice,
whole-image task evaluation and independent composed soundness/privacy/Lean
obligations remain open.
