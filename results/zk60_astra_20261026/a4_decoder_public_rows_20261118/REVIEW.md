# Observable first-layer prompt rows

For each of the three synthetic fixtures, 85 of the 149 first-layer input rows exactly match embeddings of the fixed public prompt. The 64 image-token positions are supplied by the image adapter. The first image token is at zero-based position 70. Among the 85 public rows, 15 follow that first image token. [Input and output checks](RESULT.json)

Causal attention makes the first 70 output rows reproducible from the public prompt prefix and public parameters. Two public-only evaluations used different suffixes, first zeros and then repeated public embeddings. Both reproduced all 215,040 output words in the prefix of each fixture, 645,120 words in total. The check used the authenticated 128-position export for the short public evaluations. Its coefficients agree with the 149-position fixture on the shared positions, as checked in the parameter derivation. [Public-only replay](public_rows.py), [parameter derivation](../a4_decoder_arithmetic_review_20261117/PARAMETER_REVIEW.json)

The native development statement identifies the trained model and context, and includes input and output commitment roots for padded 256 × 4096 planes. Each commitment has 256 data rows and five additional rows. Its implementation samples fresh secret randomness for each role. Reproducing the prompt rows does not determine an independently sampled root. The saved-receipt verifier takes its expected root pair from the receipt claim. Checking an externally supplied expected root and proving what the receipt hides remain separate obligations.
