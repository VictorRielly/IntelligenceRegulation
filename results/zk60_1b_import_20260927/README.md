The importer accepts only explicit SiLU, untied, bias-free, ordinary causal Llama geometry with explicit RMS epsilon and RoPE theta, no RoPE scaling/sliding-window variant. It supports a single safetensors file or an indexed sharded checkpoint. It rejects missing/extra tensors, unsupported dtype, incorrect output/input orientation, unsafe shard names, duplicate JSON keys, noncontiguous or overlapping payloads, shape/offset/size mismatch and mismatched source hashes. Complete files are SHA-256 pinned in 1 MiB chunks; the inventory also records config, index, header and each tensor digest. `layer(n)` yields nine tensor descriptors without loading values. `read_tile` returns at most 1 MiB by default and rechecks the tensor digest while streaming it, so a file changed after inventory is refused. The CLI prints only identities and dimensions, never tensor values.
