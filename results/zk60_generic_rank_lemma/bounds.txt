SENSITIVITY: what if a draw this lemma places in Fp2 is really in Fp?
  a lambda or a terminal-mask e in the base field: Norm(x) = x^2, so
    Pr[Norm = 0] rises from 1/p^2 = 2^-128.0 to 1/p = 2^-64.0 per draw.
    private-block-t32-poc     : 224 such draws -> 2^-56.19 (instead of 2^-120.19)
    private-attention-t32-poc : 153 such draws -> 2^-56.74 (instead of 2^-120.74)
  the proximity pair in the base field: wedge(a, b) = a.c0*b.c1 -
    a.c1*b.c0 = 0 identically when both c1 = 0, so the refusal would
    fire on EVERY run and no proof would ever be produced.  The
    extension-field draw at zkp-core/src/pcs.rs:853 is load-bearing
    for completeness, not only for the bound.
