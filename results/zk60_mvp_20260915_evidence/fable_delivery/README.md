# Original Fable 5.1 delivery

These four files are preserved byte-for-byte, with hashes in `index.json`.
They record the delegated author's proposal and its unexecuted status in that
session. They are **not the accepted integration**. In particular, the proposed
removal of the external-root requirement and the proposed adaptive privacy
argument were not accepted.

Use the integrated scripts/tests in the repository's top-level `scripts/` and
`tests/` directories. These archival copies use checkout-relative paths and
are not runnable from this nested archive. See
[Codex's review](../../../docs/zkmatrix-poc/ZK60_MVP_REVIEW.md) and
`../security_probe.json` for the independently executed, qualified diagnostic.
