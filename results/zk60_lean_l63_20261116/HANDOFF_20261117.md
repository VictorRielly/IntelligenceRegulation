## 6. How to work

- **Single build.**
  - Write a plan file results/zk60_lean_l63_20261116/planN.txt with lines like "build ZK60Formal.RunStgShieldX".
  - Run: `python3 <WT>/results/zk60_lean_l63_20261116/run_guarded.py lean-l63-iterN <OUT>/iterN.log <OUT>/iterN.done /bin/bash <OUT>/iter.sh <OUT>/planN.txt`, background, then wait for iterN.done.
  - run_guarded.py uses guard class build and the default poll. L63_POLL_SECS overrides the poll for one job.
  - Read errors with `grep -A20 "^error" iterN.log`.
  - The last iteration used was 54; the last check was merge6. Continue at iter55 and merge7.
- **Full check:** `run_guarded.py lean-l63-mergeN <OUT>/check_mergeN.log <OUT>/check_mergeN.done /bin/bash <OUT>/check_l63merge.sh`.
  - The script does a root build, an axiom audit of MINE (gen_axioms.py), axioms_blkalive.lean (blkAlive, pinsHd, dz, pdz), a source scan, the generator --check runs, name clashes, the root diff against BASE=be99d6f1, and regressions L6/L5/L11/L1.
  - When you add a file: add it to MINE_NEW in check_l63merge.sh, to the files list and imports in gen_axioms.py, and an import line to formal/ZK60Formal.lean. Add new tops to axioms_blkalive.lean and new generators to the generator loop.
- **Generators.** Rerun l63_mk_topdz.py / l63_mk_toppd.py (`python3 <script> <WT>`) only if their sources (RunBlkAliveR13 / RunBlkPinsHd) or the binder lists change. They are checked with --check.
- **Timings.** Single files take 5-20 s. The check takes ~110-136 s and peaks at 3.7-4.5 GiB. Expect waits on the heavy lock: Antigravity's jobs and g2_full_suite held it for many minutes.
- **Pitfalls:**
  - shdRkBase and shdRkD are irreducible globally: use the equation lemmas.
  - A binder named QB shadowed the type QB; I renamed it Qb.
  - `rw` fails when the rewritten term appears in a binder type (Fin (...)) or in a Fin proof. Use a general lemma with an equation hypothesis and subst it (eqPoly_mbK), or `generalize` the value first (x0 in l63_mk_toppd.py).
  - if_pos, if_neg, dif_pos and dif_neg are deprecated (warnings count as failures): use ite_eq_left/right and dite_eq_left/right.
  - omega does not see through Fin literals: `show i.val = lw` first.
  - In `fun` against `∀ {N}` use `intro`.
  - clog2 lives in ZK60.Exec.StageV.
  - Decidable/`set` variables can block `rw`; `refine h.trans ?_` helps.
  - Simp lemmas that turn out unused raise linter warnings.
  - ZK60.ProtocolClassify.mb shares its short name with ZK60.Exec.StageCheck.mb (benign).
