## 6. Pitfalls met this leg

- **Whole-chain twins by generator are cheap to build**: the 33 twins (≈9,000 lines) built in 94 s first time
  (iter147, peak 4.46 GiB), because each proof is the source's text. Keep twins textual; do not re-prove.
- A twin's inserted hypothesis must only mention binders declared BEFORE it: `ops` followed `hdin` in the eb/rc
  theorems ("Unknown identifier `ops`", iter145). Moving the binder changes positional calls: the generator patches
  the three positional call sites and asserts each pattern occurs once.
- `(ops :` also matches the named argument `(ops := …)` in proof bodies: match the binder as `\n    (ops : `.
- Private declarations copied into a twin must be renamed (the name-clash script flags a name declared twice in the
  lane, and a clash with RunBlkPinsHd's privates otherwise); proofs of `0 < 26` under a renamed private constant are
  still accepted where the original's types expect the original constant (proof irrelevance).
- After `unfold stgΦR` the window function stays a beta-redex (`(fun v x => …) v hh.1`): `beta_reduce` before
  `rw [hw]`.
- `cl_agree`'s `C.N`, `C.R`, `C.n`, `C.Q` against `2 ^ 11`, `6`, `2 ^ 8`, `256` at `CinB` unified cheaply when the
  existence statement is given as an explicit `have hon : … :=` type (cap 16 GiB, peak 4.46 GiB); keep that form.
