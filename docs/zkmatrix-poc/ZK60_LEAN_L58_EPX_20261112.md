## 1. In plain words, for Victor

**The question.** Lanes L51 and L52 repaired how Lean reads the classifier's input commitment root from the 84-byte `expected-IO` header message, and lane L55 proved the verdict link and all 27 closing openings after part 0. That still left a split at the input commitment itself (`L52-1`, `L52-5`):
- the column-proximity test read its matrix `Ux` and column set `Xx` through L51's unchecked column reader `colXM`;
- the commitment's opening extractor `ops` needed tag-checked whole openings (`ebOpenX`) with canonical Goldilocks words (`< p`).

Because `colXM` could keep a column whose Merkle salt/leaf tags failed or whose words were non-canonical while the tag-checked extractor dropped it, `hread` ("the column test reads the same columns `ops` extracts") was not met for every prover, and `ops`, `hops`, `hcan`, `hread`, `mk`, `hE` remained open premises on the top theorem.

**The fix (PROVED and CHECKED).**
- **One checked extractor (`epxAt`).** Both the column test (`exXx`, `exUx`) and the commitment's opening map (`epxOps`) now read from the same tag-checked descent `ebOpenX` at the statement's input root (cut at position 1's `expected-IO` absorb), keeping an opening only when all `rows` field words are canonical (`< p`).
- **Why dropping non-canonical words is sound (CHECKED).** Both production wire readers (`token_io.rs` and `private_block/wire.rs` `Reader::fp`) and `owner_rebuild_root` reject any word `≥ p` (`l58_tagcheck.py`, C1 and T4), so no accepted opening ever contains a non-canonical word.
- **Same soundness budget (PROVED).** Where a sampled column verifies on an accepted run, both `extractCol` and `ebOpenX` return it unless L16's hash-collision / fresh-hit event `ExtBad` occurs (`epx_open_of_opens`). Widening `ebEvIn` to `exEvIn` ("either extractor misses a verifying column") keeps the exact bound `εxRun q`, so the R13 run extraction budget remains **55,852,891 of 67,108,864 units (83.2 %)** (`ex_total`).
- **Premises gone (PROVED).** On the restated chain ending at **`ex_productionReadyL_epP_codeH`**, `hBal` is re-proved on the checked matrix (`ex_xB_alive`), `hops` (`ex_hops`), `hcan` (`ex_hcan`) and `hread` (`epxH_at_root` + `ab_rdIn_at1`) are proved outright, the commitment's Merkle tag is unified with the run verifier's (`tagc := tag`, CHECKED across 5 Rust functions), and the abstract `Salt` / `mk` / `hE` group is instantiated with the concrete opening record `EpxSalt Rr`.

**What remains at the input endpoint.** Only `hdzero` (non-token padding positions decode to zero, which waits on stage IN-C's soundness wiring in lane L60) and the concrete 1-row `hplace` fact (`Fin 1 → Fin Rr` is trivially injective at T128, discharged when instantiating Shieldstral in GA-4).
