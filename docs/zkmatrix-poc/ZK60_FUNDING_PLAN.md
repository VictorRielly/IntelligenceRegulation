## Decisions only Victor can make (they gate the rest)

1. **Patent first?** Publishing (a preprint, a public Manifund page, an
   open-source release under a grant) makes the method prior art. If you want
   a patent, file a US provisional first ($65–$325 in USPTO fees plus attorney
   time). If you don't, open publication fits D43(b).
2. **Open-source scope.** Foresight requires the funded work to be open
   source; the Ethereum Foundation, NLnet and similar programs do too. The
   plan scopes these grants to the verifier, spec and benchmarks. Since you
   want other companies to use the technology, a wider open release is also
   consistent; it changes the VC story to open-core.
3. **Company.** Form a Delaware C-corp now: every equity route and every
   federal route needs one. Grants taken as an individual before then need a
   clean assignment of the IP to the company.
4. **YC as a solo founder or with a co-founder** — YC weighs this; say how
   you work, including the AI-agent team.
