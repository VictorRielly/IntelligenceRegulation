## What the new generator does

`scripts/zk60_endpoint_view.py` adds an explicit `EndpointPlan` that contains
only fold coefficients, claim row/column weights, query positions and geometry.
The generator receives **no captured vector, terminal or column value**, and
no real endpoint witness or commitment secret. A test deletes every captured
field-output value before plan extraction and gets exactly the same plan and
deterministic test output.

Given that plan, the generator sets two dummy data rows to zero, samples five
message-mask/proximity rows and seven pad polynomials in the uniform-Fp model,
then computes both complete public vectors, the individual terminal and all
seven words at each selected encoded column. It validates those equations.

For each new public view, round 24's unchanged conditional sampler constructs
a compatible preimage for a nonzero chosen dummy plane. That plane is the same
for the corresponding endpoint role across the two fresh proof cases. The
new tool thus generates the standalone public endpoint observations that were
inputs to round 24. It still does not sample A/H/W/CFS jointly, make their
terminals agree with these views, or produce a complete FFN proof.

## Exact fixed-coefficient scope

Fix a plan with rank four on the five random message rows, and let q be its
number of distinct queried columns (q <= 256). The endpoint has 3,072 random
base-field coordinates: 5*256 message words plus 7*256 pad coefficients.

Round 24's explicit fibre parametrization supplies 256 + 3(256-q) free
coordinates for every feasible view and every chosen data plane. It works in
both directions between any two data choices: given a feasible view for one,
it constructs a preimage for the other. Therefore the feasible public images
coincide, with equal fibre sizes. Uniform independent masks/pads induce the
same uniform image distribution for every data choice, of dimension
2,048 + 3q. The zero-data generator samples that image.

This is a standalone algebraic statement **conditional on fixed coefficients
and positions**, with nondegenerate rank and independent uniform field words.
It does not establish that conditioning an actual adaptive Fiat–Shamir proof
on its later coefficients leaves those words uniform. It does not account for
the additional observations of A/H/W/CFS. The public generator, conditional
preimage checks and rank calculations are components of the unfinished joint
construction, not a full privacy theorem for the implemented profile.

## Exact arithmetic and review recomputation

The new tool includes the exact rational reduction-distance ledger discussed
in the disposition. Exhaustive small-domain counts independently verify the
formula, including input domains smaller than the modulus and exact divisibility.
Shift and product controls confirm the upper-bound interpretation.

For Goldilocks and uniform 128-bit input, the per-word distance is just below
2^-96. The 6,144 endpoint mask/pad draws give an unconditional hybrid upper
bound about 2^-83.415 to uniform words, or twice that for comparing shifted
distributions via uniform. This is neither a visible-view lower bound nor a
whole-proof bound; production PRG, adaptive and acceptance-conditioning effects
are explicitly excluded. The code does not change real randomness generation.

O11's ranks were recomputed, rather than merely testing its saved expectations:
both modes give zero-sum steps 0/2/4, zero added public-identity rank, and 256
for endpoint mask ablation. Artificially aliasing all H data gives 2, as
reported. This remains one counterfactual, not a proof that omitting arbitrary
true nonlinear cross-proof H relations is harmless. The rank engine is still
O8's unchanged engine; no independent implementation is claimed.
