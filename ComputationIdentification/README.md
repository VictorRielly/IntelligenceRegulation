# Computation Identification

## Description

In this folder we will implement the zero knowledge proofs for proving the identity of AI
systems on the network. We imagine every AI model will publish a zero knowledge proof of the
validity of the model output: namely that the output truly came from the publishing model. We
aim to prove identity with no information leakage, and in a way that introduces negligible
computational overhead. We will alsoo provide theory and tests of the reliability of the proof. 
How much computation is required to be sufficiently certain of the proof of identity.
