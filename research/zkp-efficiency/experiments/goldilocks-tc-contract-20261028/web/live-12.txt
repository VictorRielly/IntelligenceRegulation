L182: # ICICLE v4.0.0 Release Notes
L183: ## 🎉 Major Release: ICICLE v4.0.0
L184: 
L185: We're excited to announce the release of ICICLE v4.0.0! This major version introduces significant improvements to the API design, making it more intuitive, object-oriented, and developer-friendly across all supported languages.
L186: ## 🚀 Key Highlights
L187:   * Object-Oriented Field API: Complete redesign of field operations from static methods to instance methods
L188:   * Method Chaining Support: Write more concise and expressive code with method chaining
L189:   * Improved Rust API: Better trait design with standard operator overloading
L190:   * Enhanced Program API: Reorganized Program module with better type safety
L191:   * Backward Compatibility: Comprehensive migration guides for v3 to v4 transition
L192:   * Post Quantum: Implemented a NIST FIPS203 (ML-KEM) protocol on CUDA, fully open-source
L193:   * Lattice Based Cryptography: Add support for Lattice based cryptography, with integer ring support and a full LaBRADOR prover (soon announced)
L194: ## 🔄 Breaking Changes

L205: #### Arithmetic Trait Redesign
L206: 
L207: The `FieldImpl` trait has been deprecated and split into focused, orthogonal traits
