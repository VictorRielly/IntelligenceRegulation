Question: can `gpu/cuda.rs::columns_chunked_zk` replace its full `rows*cols_out` device gather buffer and full downloaded host buffer with one row-chunk buffer while preserving every returned per-query column? Baseline: chunked hiding reencoding already exists. Native fused gathering emits distinct indices once, then the host reconstructs every query, including duplicates in their original order. Unfused gathering emits one output column per query. Both retain full device output, downloaded u64 output and newly copied Fp columns until return. This experiment adds no new query deduplication.
